SubSell Auto-Reply

Configure the bot once here → it runs on every computer's Chrome.

1 · Get the extension required

The replying happens inside a Chrome extension — a web page can't type into Messenger by itself. Install it once per computer, then come back here to set it up.

Not on the Chrome Web Store yet — install it manually (2 minutes, free):

  1. Unzip the download. You should see manifest.json directly inside the folder.
  2. Open chrome://extensions and turn on Developer mode (top-right).
  3. Click Load unpacked and pick that folder.
  4. The SubSell icon appears. Done — now sign in below to configure it.

2 · Sign in

Sign in to edit the settings shared by all your computers.

The "send a demo video once per chat" upload is per-machine. A video file is megabytes and can't ride along in the synced settings, so you upload it (and toggle it on + set the delay) inside each extension: its Settings → General → "Send demo video(s) once per chat". Only the URL library above and the on/off behavior sync; the actual file lives on each computer.

Activity logs live on each computer, not in the cloud. Every machine replies on its own, so each extension keeps its own log of the last 500 sends (buyer message + reply + action).

To review what an account has been sending:

  1. On that computer, click the SubSell icon → Settings ▸.
  2. Open the Activity log tab.
  3. Use Refresh, Export JSON, or Clear log there.

Tip: review each account's log now and then to make sure it still sounds like you — identical wording across accounts is a fingerprint.
