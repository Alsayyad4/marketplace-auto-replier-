SubSell Auto-Reply — Privacy Policy

Last updated: 2026-06-07

SubSell Auto-Reply ("the extension") is a single-operator tool that helps a seller auto-reply to their own Facebook Marketplace / Messenger buyer conversations using the Anthropic Claude API. This policy explains exactly what data it touches and where that data goes.

Operator action required: replace the contact email below with a real address before you publish to the Chrome Web Store.

What the extension accesses

  • Messenger / Marketplace conversation text — when you turn the bot ON, it reads the latest message in your open conversations so it can generate a reply. Only the relevant recent message text is used.
  • Your Anthropic API key — you provide this. It is used to authenticate requests to Anthropic on your behalf.
  • Your settings — business info, listings, prompts, follow-ups, and limits that you enter.

Where data is sent

  • Anthropic (api.anthropic.com) — the buyer's latest message and your system prompt are sent to Anthropic's Claude API to generate the reply. See Anthropic's privacy policy at anthropic.com/legal/privacy.
  • Facebook / Messenger — generated replies are typed into your own Messenger conversations, the same as if you typed them.
  • Optional: your own cloud (Supabase) — if you choose to use the cloud dashboard, your settings (including your API key) are stored in a database project you control, protected by row-level security, so the same configuration can apply to all your computers. This is optional and off unless you set it up.

Where data is stored

  • On your computer — settings and your API key are stored locally via chrome.storage. They may sync across Chrome instances signed into the same Google account (chrome.storage.sync) if you use that feature.
  • Demo videos you upload stay on that computer only.
  • Activity log (the bot's recent replies) is stored on that computer only.

What we do NOT do

  • We do not run any server that collects your data. The extension talks only to Anthropic, to Facebook/Messenger, and — if you enable it — to your own cloud.
  • We do not sell, share, or use your data for advertising or analytics.
  • We do not collect data from anyone other than the operator running the tool.

Your control

  • Delete the extension to remove its locally stored data, or clear it from chrome://extensions → the extension → site/storage data.
  • Rotate or remove your Anthropic API key at any time in the settings.
  • If you use the cloud dashboard, you can regenerate your config key or delete your row/account in your Supabase project.
