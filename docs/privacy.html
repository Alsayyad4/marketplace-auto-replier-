SubSell Auto-Reply — Privacy Policy

Last updated: 2026-10-09

SubSell Auto-Reply ("the extension") is a tool for one business: it answers that business's own Facebook Marketplace buyer messages, inside the business's own Messenger account, with the Anthropic Claude API and the business's own settings. It is used by the business that installs it (the "operator") on the operator's own computers. This policy lists exactly what data it touches, where that data goes and how long it is kept.

What the extension reads

  • Messenger / Marketplace conversations of the operator's own account — when the operator switches the bot ON, it reads the recent messages of a conversation so it can write a reply, and the conversation list to find buyers waiting for an answer. It runs only on messenger.com and facebook.com.
  • The operator's settings — business information, prices, instructions, corrections ("lessons"), follow-up texts, limits, and the operator's Anthropic API key.
  • The operator's cloud login (optional) — an email and password for the operator's own cloud project, used to keep all the operator's computers on the same settings.

Where data is sent

  • Anthropic (api.anthropic.com) — the buyer's recent messages in that conversation and the operator's instructions are sent to Anthropic's Claude API to write the reply, authenticated with the operator's own API key. See anthropic.com/legal/privacy.
  • Facebook / Messenger — the reply (and, if the operator configured one, the operator's demo video) is sent in the operator's own conversation, as if the operator had typed it.
  • The operator's own cloud project (Supabase, optional, configured by the operator) — stores the operator's settings so every computer of the operator uses the same ones, the operator's demo videos, and an activity log: the buyer's message and the reply that was sent, which computer sent it, and when. The log lets the operator see what the bot said and stops two of the operator's computers from answering the same buyer twice or sending the same video twice. The extension also records the AI usage counts (number of requests and tokens — no message text) so the operator can see the cost.

The extension sends data nowhere else. The developer runs no server of its own that collects data from the extension.

How long data is kept

  • Activity log messages are deleted automatically after 5 days; the record that a demo video was sent to a conversation is kept 60 days (so the same buyer is never sent it twice); AI usage counts 35 days.
  • Settings stay until the operator changes or deletes them.
  • On each computer the extension keeps its settings, its recent state and the downloaded demo video files in Chrome's extension storage and in the Downloads folder (SubSell-videos) until the extension is removed.

What we do NOT do

  • We do not sell, rent or share any data with third parties.
  • We do not use any data for advertising, profiling, creditworthiness or anything other than answering the operator's own buyers.
  • We do not collect data from people who are not the operator's buyers in the operator's own conversations, and we do not track browsing on any other website.

Security

  • All traffic uses HTTPS.
  • The cloud project is protected by row-level security: the operator's login can read and write only the operator's own data.

Your control

  • Switch the bot OFF at any time from the extension's popup.
  • Remove the extension to delete everything it stored on that computer.
  • Change or remove the Anthropic API key at any time in the settings.
  • Delete the activity log, the settings or the whole cloud account in the operator's own cloud project at any time.
  • A buyer who wants their messages removed can ask the operator, or write to the contact below.
